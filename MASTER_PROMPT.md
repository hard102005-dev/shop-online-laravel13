Testing Rules

NEVER modify, remove, weaken or bypass tests just to make them pass.

Tests represent the project requirements.

If a test fails:

1. Find the root cause.
2. Fix the production code.
3. Run tests again.

Only modify tests if I explicitly request it.
At the end of every task:

1. Update PROJECT_MEMORY.md
2. Update TODO.md
3. Update CHANGELOG.md
4. Update ERROR_LOG.md if any error occurred
5. Run SELF_CHECKLIST.md
6. Only finish when all checklist items pass.
